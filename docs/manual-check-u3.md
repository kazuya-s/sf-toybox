# 手の確認 — U3 変更セットの中身一覧

公開の前に、開発者組織か Sandbox で手で確かめる手順です（U3 infrastructure-design/cicd-pipeline.md「U3 の手の確認」）。**本番組織では確かめません。**

## 準備

1. `npm ci` と `npm run build` を実行する。
2. Chrome の `chrome://extensions` で「デベロッパー モード」を ON にし、`.output/chrome-mv3` を「パッケージ化されていない拡張機能を読み込む」で読み込む。
3. 開発者組織か Sandbox に、コンポーネントを数件入れた送信変更セットを用意する。1 ページに収まらない件数（コンポーネントが多い変更セット）も 1 つ用意すると、進み具合を確かめられる。
4. 拡張機能の詳細で、求める権限が「ストレージ」だけで、`tabs`・`downloads`・`clipboardWrite` がないことを確かめる。

## 確かめること

| #   | 操作                                                                     | 期待すること                                                                                                                             | 結果 |
| --- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1   | 送信変更セットの詳細画面で、ツールバーのアイコンを押す                   | 「読み込んでいます… (n / m ページ)」が出たあと、一覧が出る。見出しに「変更セット: <名前>」と「m 件」が出る。絞り込み欄にフォーカスがある |      |
| 2   | 一覧の最初の並びを見る                                                   | 種類、その次に API 名の順（大文字と小文字を区別しない）。親オブジェクトがない行は「-」                                                   |      |
| 3   | 名前で絞り込み、種類を選び、列見出しを押す（Enter でも）                 | 行が絞り込まれ、「表示中 n 件 / 全 m 件」が変わる。同じ見出しを 2 回押すと降順になる                                                     |      |
| 4   | 一致しない名前を入れる                                                   | 「条件に一致するコンポーネントがありません」と「絞り込みを解除」が出て、コピーと CSV のボタンが押せない。「絞り込みを解除」で元に戻る    |      |
| 5   | 「一覧をコピー」を押し、表計算ソフト（Excel など）に貼る                 | 1 行目が見出しで、表の順に貼られる。`=` や `+` で始まる名前があっても数式として動かない                                                  |      |
| 6   | 「CSV で保存」を押し、保存した CSV を Excel で開く                       | ファイル名が「<変更セットの名前>_<YYYYMMDD>.csv」。日本語が文字化けしない                                                                |      |
| 7   | 送信変更セットの詳細画面ではない画面（設定のホームなど）でアイコンを押す | 「送信変更セットの詳細画面で開いてください」                                                                                             |      |
| 8   | 設定画面で「変更セットの中身一覧」を OFF にし、詳細画面でアイコンを押す  | 「このツールは OFF です」と「設定を開く」。「設定を開く」で設定画面が開く                                                                |      |
| 9   | 詳細画面を開いたままログアウトし、アイコンを押す                         | 「Salesforce にログインし直してから、もう一度開いてください」                                                                            |      |
| 10  | 設定で OFF から ON に戻し、詳細画面を再読み込みせずにアイコンを押す      | 「読み込めませんでした」と「画面を再読み込みしてから、もう一度開いてください」。再読み込みすると一覧が出る                               |      |
| 11  | 設定画面の「最近のエラー」を見る                                         | 失敗したときの記録に、変更セットやコンポーネントの名前が入っていない                                                                     |      |

## 記録

- 確かめた日と組織の種類（開発者組織か Sandbox）、Chrome の版を書く。
- 期待と違ったときは、画面の目印（`src/page/page-context.ts`、`src/salesforce/markers.ts`）を見直す。
