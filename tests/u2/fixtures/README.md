# U2 のテストの HTML の例

ここにあるのは、U2 の自動テストで使う Salesforce の画面の例です。リポジトリは公開なので、組織のデータを入れないよう次の手順で扱います（infrastructure-design/cicd-pipeline.md「テストの HTML の例」）。

## 例を足すときの手順

1. **実際の画面を保存しない**: ブラウザの「名前を付けて保存」や、開発者ツールからのコピーで作ったファイルは置きません。保存したファイルはリポジトリの外でも残さないでください。
2. **構造だけを写す**: 手の確認（`docs/manual-check.md`）で実際の画面を見て、目印（`src/salesforce/markers.ts`）に必要な要素・クラス・属性・列の見出しだけを手で書きます。
3. **架空の値だけを使う**: 次の表の値だけを使います。

   | 項目                               | 使ってよい値                                                                      |
   | ---------------------------------- | --------------------------------------------------------------------------------- |
   | ホスト名                           | `example.my.salesforce.com`                                                       |
   | ID                                 | `0A2000000000001`、`00N000000000001` のような、先頭 3 文字のあとが 0 の並びのもの |
   | 隠し項目の値                       | `test-token`、`test-viewstate` のように `test-` で始まるもの                      |
   | 名前                               | `TestClass`、`Test__c`、`Field_A__c` などの架空のもの                             |
   | メールアドレス・個人名・URL の引数 | 入れない                                                                          |

4. **自動の確認を流す**: `npm run check:fixtures` を実行し、通ることを確かめます。CI でもテストの前に流れます。
5. **作者が目で確かめる**: 自動の確認では見つからない組織の名前・個人名・社内の言葉が入っていないかを、作者が目で確かめてからコミットします。

## いまある例

| ファイル                                 | 内容                                                                  |
| ---------------------------------------- | --------------------------------------------------------------------- |
| `detail-single.html`                     | 詳細画面（1 ページ、状態 open、親オブジェクトが空の行）               |
| `detail-page1.html`〜`detail-page3.html` | 詳細画面（3 ページ、2 ページ目の先頭に 1 ページ目の最後の行が重なる） |
| `detail-uploaded.html`                   | 詳細画面（アップロードの記録があり、状態 uploaded）                   |
| `detail-unknown.html`                    | 詳細画面（状態の手がかりがなく unknown、行なし）                      |
| `detail-missing-column.html`             | 詳細画面（表の「Type」の列が欠けた形）                                |
| `detail-after-add.html`                  | 追加したあとの詳細画面（日本語の見出し）                              |
| `add-page1.html`、`add-page2.html`       | 追加画面（カスタム項目、2 ページ）                                    |
| `add-no-form.html`                       | 追加画面（フォームなし）                                              |
| `login.html`                             | ログイン画面                                                          |
| `permission-denied.html`                 | 権限がない旨の画面                                                    |
| `not-found.html`                         | 対象のデータがない旨の画面                                            |
| `script.html`                            | `<script>`・`onerror`・`onload` を含む画面                            |
