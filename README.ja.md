# sf-toybox

English: [README.md](README.md)

Salesforce の設定画面を少し便利にする、小さなツールを集めた Chrome 拡張機能です。ツールごとに設定画面で ON/OFF を切り替えられます。最初はすべて ON です。

## ツール

| ツール                   | 動く場所                                                        | できること                                                                                                                                          |
| ------------------------ | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一覧の表示件数の切り替え | 古い形式の設定の一覧画面（Apex クラス、Visualforce ページなど） | 一覧の上にバーを出し、1 ページの件数を切り替える（100 / 500 / 1000 / 2000、または好きな数）                                                         |
| 変更セットの中身一覧     | 送信変更セットの詳細画面で、ツールバーのアイコンから            | 変更セットのコンポーネントを、全ページ分まとめて 1 つの一覧で見る。絞り込み・並べ替え、タブ区切りでのコピー、CSV（BOM 付き UTF-8）での保存ができる  |
| 変更セットへの追加支援   | 送信変更セットの「追加」画面                                    | 候補を名前や親オブジェクトで検索し、まとめて選んで 1 件ずつ追加する。失敗したらそこで止め、追加できたもの・できなかったもの・試さなかったものを示す |

画面の言語は、ブラウザの言語に合わせて日本語か英語になります。

## プライバシー

- Salesforce のデータをブラウザの外へ送りません。通信の相手は、開いている画面と同じ Salesforce の組織だけで、ログイン中のセッションをそのまま使います。
- 保存するのは、ツールごとの ON/OFF と、短いエラーの記録（ツールの識別子・エラーの種類・時刻・文言の識別子）だけです。保存先は `chrome.storage.local` です。URL、レコードの値、変更セットやコンポーネントの名前は保存しません。
- 外部からコード、スタイル、フォントを読み込みません。すべて拡張機能の中に含めています。
- 求める権限は `storage` だけです。manifest の項目ごとの理由は [docs/store/permissions.md](docs/store/permissions.md) にあります。

## 動く環境

- Chrome 120 以降
- 設定画面を使える Salesforce。変更セットのツールには、変更セットを扱う権限が要ります。

## ソースから試す

まだ Chrome ウェブストアには公開していません。ソースから試すときは次のとおりです。

```bash
npm ci
npm run build
```

1. `chrome://extensions` を開き、「デベロッパー モード」を ON にする。
2. 「パッケージ化されていない拡張機能を読み込む」で `.output/chrome-mv3/` を選ぶ。
3. 拡張機能の「詳細」→「拡張機能のオプション」で設定画面を開き、ツールの ON/OFF を切り替える。

設定の変更は、Salesforce の画面を再読み込みすると反映されます。

> 変更セットへの追加支援は、まず開発者組織か Sandbox で試してください。組織を書き換える唯一のツールです。

## 開発

Node.js 22 が要ります。

| コマンド                     | 内容                                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------------- |
| `npm run lint`               | ESLint、Prettier の確認、TypeScript の型の確認                                         |
| `npm run build`              | WXT で拡張機能を `.output/chrome-mv3/` にビルドする                                    |
| `npm run test -- --coverage` | Vitest のテストをカバレッジつきで流す（行のカバレッジが 80% 未満なら失敗）             |
| `npm run check:manifest`     | ビルドした manifest を確かめる（権限、matches、同梱するファイル、外部 URL がないこと） |
| `npm run check:fixtures`     | テストのデータに実際の組織のデータが入っていないことを確かめる                         |
| `npm run zip`                | Chrome ウェブストアに出す zip を作る                                                   |

CI（GitHub Actions）は、`develop` と `main` への push とプルリクエストで、上のコマンドをすべて流します。

テストは Node と happy-dom の中で動き、実際の組織にはつながりません。本物のブラウザと組織でしか確かめられないことは、手の確認の手順で確かめます。

- [docs/manual-check.md](docs/manual-check.md) — 土台、件数の切り替え、Salesforce とのやり取り
- [docs/manual-check-u3.md](docs/manual-check-u3.md) — 変更セットの中身一覧
- [docs/manual-check-u4.md](docs/manual-check-u4.md) — 変更セットへの追加支援

手の確認は本番組織では行わないでください。

### フォルダの構成

| 場所                                                        | 中身                                                                             |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `entrypoints/`                                              | 拡張機能の入口（content script、設定画面、ツールバーの画面、後から読み込む部品） |
| `src/settings/`、`src/storage/`、`src/errors/`、`src/i18n/` | ツールの ON/OFF、ローカルの保存、エラーの記録、文言                              |
| `src/page/`                                                 | 画面の判定と、拡張機能の中のメッセージの窓口                                     |
| `src/page-size/`                                            | 一覧の表示件数の切り替え                                                         |
| `src/salesforce/`、`src/changeset/`                         | 同じ組織の Salesforce とのやり取りと、変更セットの読み込み・追加                 |
| `src/changeset-viewer/`                                     | 変更セットの中身一覧（ツールバーの画面）                                         |
| `src/changeset-add-assist/`                                 | 変更セットへの追加支援                                                           |
| `public/_locales/`                                          | 日本語と英語の画面の文言                                                         |
| `scripts/`                                                  | ビルドとテストのデータの確認スクリプト                                           |
| `tests/`                                                    | 単体テストと結合テスト                                                           |

Salesforce の画面を読み取るための目印は、`src/salesforce/markers.ts`（と `src/page/page-context.ts` の `PAGE_MARKERS`）の 1 か所にまとめています。Salesforce の画面が変わったときは、ここを直します。

### ブランチ

日々の変更は `develop` に入れ、リリースのときに `develop` から `main` へ入れます。

## 不具合の報告

不具合の報告のひな形を使って Issue を作ってください。設定画面の「最近のエラー」の内容を書き写してもらえると助かります。組織の名前、URL、レコードの中身は書かないでください。
